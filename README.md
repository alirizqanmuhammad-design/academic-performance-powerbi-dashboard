# Academic Performance & Portfolio Dashboard

A high-end, interactive multi-page academic analytics dashboard built using **Power BI**, designed with a custom **Neon Dark Mode** theme (`#0B0E14` background with vibrant cyan `#00F0FF` and emerald mint `#39D353` accents). 

This project transforms traditional academic transcripts into an immersive visual analytics experience, evaluating undergraduate milestones, grade distributions, and semester-over-semester GPA trends.

## 🛠️ Key Features & Technical Highlights
- **Custom UI/UX Theme:** Tailored dark-mode color scheme optimized for visual hierarchy and data readability.
- **Dynamic Filtering & Slicers:** Interactive filtering across Semesters, Course Categories, and Letter Grades.
- **Advanced DAX & Interactions:** Configured custom *Edit Interactions* so that trend line charts remain contextual and fully mapped across academic milestones even when specific semesters are filtered.
- **Visual Analytics:** Includes Donut Charts (Credit distribution), Horizontal Bar Charts (Category GPA), Column Charts (Grade counts), and Smooth Line Charts (GPA Trends).
